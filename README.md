# Scoop bucket of NeuralFoundry

Packages for [Scoop](https://scoop.sh).

```powershell
scoop bucket add neuralfoundry https://github.com/NeuralFoundry/scoop-bucket
scoop install neuralfoundry/openlitespeed
```

| Package | Description |
|---|---|
| `openlitespeed` | [OpenLiteSpeed for Windows](https://github.com/NeuralFoundry/openlitespeed-windows), a native Windows build of the OpenLiteSpeed web server |
